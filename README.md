# Portfolio

Réalisé avec React, Vite et Tailwind CSS.

Projet réalisé dans le cadre de mes études, durant mon année à Epitech Paris.

## Stack

- React 19
- Vite 8
- Tailwind CSS 3
- [React Bits](https://reactbits.dev/) — composants de la page QR

## Design

Page unique, bleu et charcoal, angles droits, composants dans le style shadcn et quelques effets
React Bits.
La page QR code (`/Portfolio/qr/`) garde son style d'origine.

## Lancer le projet

```bash
npm install
npm run dev
```

## Scripts

| Commande          | Description                            |
| ----------------- | -------------------------------------- |
| `npm run dev`     | Démarre le serveur de développement    |
| `npm run build`   | Compile le projet pour la production   |
| `npm run preview` | Prévisualise le build de production    |
| `npm run lint`    | Lance oxlint                           |
